# Stage Control – Multi Axis System

A Python-based GUI application for precise control of a **4-axis motorized stage system** in a microscopy setup using a joystick interface.

The software provides intuitive manual control, position management, safety mechanisms, and logging, designed for reliable and reproducible experimental workflows.

---

## Overview

This application enables coordinated control of:

- X/Y translation stage
- Z translation stage
- Piezo-driven fine Z stage

Control is performed via a **hardware joystick** as well as a **graphical user interface (GUI)** built with PyQt5.

The system supports both coarse and ultra-fine positioning (down to **0.1 µm resolution**), including closed-loop positioning to previously saved coordinates.

## Installation
This software is designed for **Windows** only, due to dependencies on hardware drivers for the joystick and stages.

### Requirements

- **Python 3.12**
- Hardware drivers installed for:
  - :contentReference[oaicite:0]{index=0}  
  - Standa XY stage  
  - :contentReference[oaicite:1]{index=1}  
  - Thorlabs piezo stage

### Installing Dependencies
Install the required Python packages via:

```bash
pip install -r requirements.txt
```

### Running the Application
1. Using Python directly
python main.py
2. Using a PyInstaller executable (recommended):
run
```bash
pyinstaller --onedir --noconsole --icon=icon.ico --collect-data qbstyles --exclude-module pyvisa --exclude-module pyvisa_py --exclude-module tkinter --exclude-module PyQt6 --exclude-module PySide2 --exclude-module PySide6 --exclude-module PyQt5.QtWebEngineWidgets --exclude-module PyQt5.QtBluetooth --exclude-module PyQt5.QtNetwork --exclude-module PyQt5.QtNfc --exclude-module PyQt5.QtPositioning --exclude-module PyQt5.QtMultimedia --exclude-module PyQt5.QtOpenGL --exclude-module PyQt5.QtQml --exclude-module PyQt5.QtQuick --exclude-module PyQt5.QtQuickWidgets --exclude-module PyQt5.QtSql --exclude-module matplotlib.tests --exclude-module matplotlib.backends.backend_tkagg --exclude-module matplotlib.backends.backend_wxagg --exclude-module matplotlib.backends.backend_gtk3agg --add-data "icon.ico;." --add-data "./libximc/;." --add-data "./joystick_annotated.png;." main.py
```

The built main.exe file can then be found in a dist/ directory. Only Windows is supported due to hardware driver dependencies. Linux or macOS have not been tested.

#### Notes
The dist/ folder is generated by PyInstaller and contains the standalone executable.
Logs will be written automatically to the log/ directory in the same folder as the executable.

## Hardware

The system is designed to interface with the following components:

- **Joystick:** Thorlabs MCMK4 Joystick  
- **XY Stage:** Standa motorized translation stage  
- **Z Stage:** Thorlabs MLJ250/M  
- **Piezo Stage:** Thorlabs piezo actuator (fine Z control)

Compatibility with similar hardware is possible by adding additional hardware classes.

## Features

### Joystick Control
- Direct mapping of joystick knobs to stage axes
- Enable/disable axes via hardware buttons
- Toggle zero position and Z-limit directly from the controller
- Adjustable sensitivity (velocity scaling)

### Graphical User Interface
- Real-time position display for all axes
- Manual step-based movement (down to **0.1 µm**)
- Continuous movement via button press-and-hold
- Adjustable velocity for XY, Z, and piezo stages

### Position Management
- Save arbitrary positions with custom names
- Load and move to saved positions
- Internal position manager for editing and organizing entries
- File-based persistence of positions

### Closed-Loop Positioning
- Automated movement to stored coordinates
- Convergence verification with user feedback
- Safety confirmation dialog before executing movements

### Safety Features
- Configurable **Z soft limit** to prevent collisions
- Runtime warnings when limits are reached
- Mandatory confirmation before automated movements
- Hardware homing checks at startup

### Logging
- All system events are logged to a dedicated `log/` directory
- Includes:
  - User actions
  - Stage movements
  - Hardware events
  - Warnings and errors

## Joystick & Software Controls

### Joystick Controls

- **Knobs 0–3:**
  - Knob 0 → X stage  
  - Knob 1 → Y stage  
  - Knob 2 → Z stage  
  - Knob 3 → Piezo stage  

- **Buttons:**
  - Axis buttons → Toggle knob activation  
  - A button → Toggle zero position  
  - B button → Set move limit for Z at current position  

- LED indicators on the joystick show the active state of each function.

---

### Software Controls

- **Manual movement:**  
  Press buttons for discrete steps or hold for continuous motion  

- **Step size selection:**  
  Adjustable step sizes down to **0.1 µm**

- **Z-limit:**  
  Define maximum travel range in Z-direction  
  If left empty, current position is used as limit  

- **Position management:**  
  Save, load, and navigate to stored positions  

---

## Safety Notes

- Always ensure that the stage path is free of obstructions before movement  
- Use reduced velocity or step mode when operating near limits  
- Verify hardware connections before operation  

---

## Troubleshooting

If hardware is not detected:

1. Check all cables and power connections  
2. Ensure no other software is accessing the devices  
3. Power cycle the hardware  
4. Restart the PC if necessary
